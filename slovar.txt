# slovar.txt — замены после распознавания (карта «как услышал => как надо»).
#
# Формат: одна строка = одна замена, разделитель "=>". Регистр слева не важен,
# справа пишется как надо (латиница, заглавные — как есть).
# Фразы можно из нескольких слов: заменяются целиком, длинные раньше коротких.
# Строки с "#" и пустые игнорируются. Файл читается заново, когда меняется,
# перезапуск моста не нужен.
#
# ВАЖНО: слева всегда КИРИЛЛИЦА — Vosk пишет только кириллицей, латинская
# левая часть никогда не сработает. Справа — как должно быть на самом деле.
#
# Дописать слова можно голосом: "в словарь дипсик равно DeepSeek".
# Проверить, что каждая строка действительно срабатывает: slovar.cmd -Test
